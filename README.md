# OSM · Bản đồ tài sản bảo đảm và tiện ích

Trang tĩnh (Leaflet) để nhập toạ độ tài sản bảo đảm (TSBĐ) và 3 tài sản so sánh (TSSS), đo khoảng cách, tìm tiện ích quanh vị trí (trường, bệnh viện, bến xe, chợ/cửa hàng…) và chụp ảnh bản đồ.

- Nền bản đồ: dữ liệu OpenStreetMap qua OSM France (mặc định), OSM Humanitarian (HOT), OpenStreetMap gốc (tự chuyển khi lỗi), ảnh vệ tinh Esri. Không cần API key, không dùng Google Maps.
- Tìm tiện ích: Overpass API (dữ liệu OSM).
- Chạy: mở `index.html` hoặc bật GitHub Pages (Settings → Pages → Branch `main`, thư mục `/`).
